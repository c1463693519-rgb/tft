# GLOSSARY

| Term | 定义 |
|---|---|
| Theory | Mechanics Engine 根据明确规则产生的理论计算结果 |
| Meta | 从真实对局聚合得到的观测统计 |
| DPS | 一段时间内总伤害除以时间 |
| Burst | 指定短窗口内的总伤害，例如 5 秒 |
| EHP | 针对某种伤害类型的静态有效生命近似 |
| TTD | Time To Die，在给定敌方伤害模型下的死亡时间 |
| Raw Damage | 抗性和目标侧 modifier 处理前的伤害 |
| Final Damage | 所有合法 modifier 处理后实际进入 Shield/HP 的伤害 |
| Damage Amp | 增伤类 modifier 的统一内部概念，具体 stacking 由规则定义 |
| Shred | 对目标抗性施加的降低效果 |
| Penetration | 攻击者侧穿透效果 |
| Mana Regen | 当前 Role 系统中的每秒 Mana 生成属性 |
| Effect | 装备/羁绊/技能产生的标准化可执行效果 |
| Trigger | Effect 触发条件，例如 ON_ATTACK |
| Rule Registry | 版本化 mechanics 规则集合 |
| Patch Revision | Patch/B Patch + 数据/规则修订的不可变版本 |
| Golden Test | 用已知结果锁定的关键数值回归测试 |
| Accuracy Report | 对某次 simulation 中精确/近似/不支持规则的说明 |
| Parameter Sweep | 批量改变 Armor/MR/HP/Time 并重复计算 |
| Break-even | 两个 Build 指标发生交叉的参数阈值 |
